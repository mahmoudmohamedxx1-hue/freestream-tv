    28→    28→## Key Features
    29→    29→
    30→    30→### 🔒 **Authentication & Security**
    31→    31→
    32→    32→- **Secure Admin Interface**: Full authentication system protecting the admin panel
    33→    33→- **Argon2id Password Hashing**: Industry-leading memory-hard password hashing
    34→    34→- **Session Management**: HTTP-only secure cookies with configurable TTL (24h default, 30-day remember me)
    35→    35→- **API Token System**: Multiple named API tokens with granular permission control
    36→    36→- **First-Run Registration**: On fresh install, guided admin account creation before access is granted
    37→    37→- **Local Network Restriction**: HDHomeRun emulation endpoints restricted to RFC1918 addresses only
    38→    38→- **XC Account Authentication**: All M3U and stream output endpoints authenticated via Xtream Codes accounts
    39→    39→
    40→    40→### 🔑 **API Token Permissions**
    41→    41→
    42→    42→Tokens support granular permission bitmasks:
    43→    43→
    44→    44→| Permission | Description |
    45→    45→|-----------|-------------|
    46→    46→| `Read` | GET endpoints only |
    47→    47→| `Config Write` | Modify global configuration |
    48→    48→| `Restart` | Trigger graceful restarts |
    49→    49→| `Streams` | Manage channels and streams |
    50→    50→| `Logs` | Read and clear logs |
    51→    51→| `XC Accounts` | Manage Xtream Codes output accounts |
    52→    52→| `EPGs` | Manage EPG sources |
    53→    53→| `Schedules Direct` | Manage Schedules Direct accounts |

   240→   240→

   246→   246→

   294→   294→### Hardware Accelerated FFmpeg Setup
   295→   295→
   296→   296→For hardware-accelerated transcoding, FFmpeg reads and decodes using your GPU via VAAPI. This requires:
   297→   297→
   298→   298→- FFmpeg and FFprobe installed on the **host machine**
   299→   299→- The host's DRI render node passed through to the container (`/dev/dri`)
   300→   300→- The host's VA-API driver libraries mounted into the container
   301→   301→- The container user added to the `video` and `render` groups
   302→   302→
   303→   303→```yaml
   304→   304→services:
   305→   305→  kptv-proxy:
   306→   306→    image: ghcr.io/kpirnie/kptv-proxy:latest
   307→   307→    container_name: kptv_proxy
   308→   308→    restart: unless-stopped
   309→   309→    ports:
   310→   310→      - WHATEVER_PORT_YOU_WANT_TO_USE:8080
   311→   311→    volumes:
   312→   312→      - ./settings/:/settings/
   313→   313→      - /usr/local/bin/ffmpeg:/usr/local/bin/ffmpeg:ro
   314→   314→      - /usr/local/bin/ffprobe:/usr/local/bin/ffprobe:ro
   315→   315→      - /usr/lib/x86_64-linux-gnu/dri:/usr/lib/x86_64-linux-gnu/dri:ro
   316→   316→    devices:
   317→   317→      - /dev/dri:/dev/dri
   318→   318→    group_add:
   319→   319→      - video
   320→   320→      - render
   321→   321→    healthcheck:
   322→   322→      test: [ "CMD", "curl", "-v", "http://127.0.0.1:8080/api/stats" ]
   323→   323→      interval: 30s
   324→   324→      timeout: 10s
   325→   325→      retries: 3
   326→   326→      start_period: 30s
   327→   327→```

   329→   329→## Authentication
   330→   330→
   331→   331→### Initial Setup
   332→   332→
   333→   333→On first run with no existing admin account, navigating to the admin interface automatically redirects to `/register` where you create your admin account with full name, email, username, and password (minimum 8 characters, hashed with Argon2id).
   334→   334→
   335→   335→### Login
   336→   336→
   337→   337→Authenticate with either your username or email address plus password at `/login`. Optionally check **Remember me** to extend your session to 30 days.
   338→   338→
   339→   339→### API Tokens
   340→   340→
   341→   341→API tokens allow programmatic access to the admin API without session cookies. Create tokens from the **Accounts** tab with specific permissions:
   342→   342→
   343→   343→- Tokens are 64 characters of cryptographically secure random alphanumeric characters
   344→   344→- The raw token is shown **exactly once** at creation — copy it immediately
   345→   345→- Tokens are stored as Argon2id hashes — the raw value is never stored
   346→   346→- Each token has a friendly name and a permission bitmask
   347→   347→- Tokens can be deleted (revoked) at any time
   348→   348→
   349→   349→Use tokens via the `Authorization` header:
   350→   350→
   351→   351→```bash
   352→   352→curl -H "Authorization: Bearer YOUR_TOKEN" http://your-server:PORT/api/stats
   353→   353→```
   354→   354→
   355→   355→### Changing Your Password
   356→   356→
   357→   357→From the **Accounts** tab in the admin interface, use the change password form. Requires your current password.

   384→   384→### Accounts Tab
   385→   385→
   386→   386→The Accounts tab consolidates all output account management and security:
   387→   387→
   388→   388→**Xtream Codes Output Accounts** — Create XC-compatible output accounts to expose your aggregated streams to any Xtream Codes compatible player (Tivimate, IPTV Smarters, etc.).
   389→   389→
   390→   390→Per-account configuration:
   391→   391→
   392→   392→| Setting | Description |
   393→   393→|---------|-------------|
   394→   394→| Name | Friendly name for the account |
   395→   395→| Username | XC login username |
   396→   396→| Password | XC login password (auto-generate available) |
   397→   397→| Max Connections | Maximum simultaneous streams for this account |

   438→   438→## FFmpeg Integration
   439→   439→
   440→   440→KPTV Proxy supports two streaming modes. In order to utilize FFmpeg, you must have it installed on your host machine and mount the binaries into the container.
   441→   441→
   442→   442→### Go Restreaming Mode (Default)
   443→   443→
   444→   444→- Pure Go implementation
   445→   445→- Efficient memory usage
   446→   446→- Fast startup times
   447→   447→- Basic stream processing
   448→   448→
   449→   449→### FFmpeg Mode
   450→   450→
   451→   451→- Hardware acceleration support via host GPU passthrough
   452→   452→- Advanced codec handling
   453→   453→- Handles MPEG-TS discontinuities (ad breaks, stream transitions)
   454→   454→- Comprehensive format support
   455→   455→
   456→   456→**Simple copy mode (no GPU):**
   457→   457→
   458→   458→```json
   459→   459→{
   460→   460→  "ffmpegMode": true,
   461→   461→  "ffmpegPreInput": [],
   462→   462→  "ffmpegPreOutput": ["-c", "copy", "-f", "mpegts"]
   463→   463→}
   464→   464→```
   465→   465→
   466→   466→**Common FFmpeg Arguments:**
   467→   467→
   468→   468→*Pre-Input:*
   469→   469→
   470→   470→- `"-re"` - Read input at native frame rate
   471→   471→- `"-rtsp_transport", "tcp"` - Use TCP for RTSP
   472→   472→- `"-fflags", "nobuffer"` - Disable input buffering
   473→   473→- `"-hwaccel", "vaapi"` - Enable VAAPI hardware acceleration
   474→   474→- `"-hwaccel_device", "/dev/dri/renderD128"` - Specify render device
   475→   475→
   476→   476→*Pre-Output:*
   477→   477→
   478→   478→- `"-c", "copy"` - Copy streams without re-encoding
   479→   479→- `"-c:v", "h264_vaapi"` - H.264 encoding via VAAPI
   480→   480→- `"-c:a", "aac"` - AAC audio encoding
   481→   481→- `"-f", "mpegts"` - MPEG-TS output format
   482→   482→- `"-mpegts_flags", "initial_discontinuity"` - Handle ad-break discontinuities
   483→   483→
   484→   484→## Dead Stream Management
   485→   485→
   486→   486→### Features
   487→   487→
   488→   488→- **Manual Stream Control**: Mark streams as dead or revive them from the admin interface
   489→   489→- **Automatic Blocking**: Streams exceeding failure thresholds are auto-blocked
   490→   490→- **Persistent Storage**: Dead stream data stored in SQLite
   491→   491→- **Automatic Skipping**: Proxy skips dead streams during failover
   492→   492→- **Stream Revival**: Dead streams can be restored when functional again
   493→   493→
   494→   494→### How It Works
   495→   495→
   496→   496→1. In the admin interface, navigate to any channel and click **Streams**
   497→   497→2. Each stream shows:
   498→   498→   - **▶️ Activate**: Switch to this specific stream
   499→   499→   - **🚫 Kill**: Mark this stream as dead
   500→   500→   - **🔄 Revive**: Restore a dead stream
   501→   501→3. During automatic failover, dead streams are skipped
   502→   502→
   503→   503→## Stream Watcher - Automatic Monitoring
   504→   504→
   505→   505→The Stream Watcher runs as a background service monitoring active streams every 30 seconds (15 seconds in debug mode).
   506→   506→
   507→   507→**Monitored Conditions:**
   508→   508→
   509→   509→- **Buffer Throughput**: Detects streams delivering less than 200KB per check interval
   510→   510→- **Stream Activity**: Monitors data flow timestamps (120 second inactivity threshold)
   511→   511→- **Context Status**: Detects stuck or cancelled stream contexts
   512→   512→- **FFprobe Stats**: Monitors stream stats staleness (10 minute threshold)
   513→   513→
   514→   514→**Automatic Actions:**
   515→   515→
   516→   516→- **Consecutive Failure Tracking**: Requires 3 total failures before switching
   517→   517→- **Intelligent Failover**: Automatically switches to next available healthy stream
   518→   518→- **Seamless Transition**: Maintains client connections during stream changes
   519→   519→- **Self-Recovery**: Clears failure counters when stream recovers without intervention

   718→   718→### Common Issues & Solutions
   719→   719→
   720→   720→**Problem**: Can't access admin interface
   721→   721→
   722→   722→- ✅ On first run, navigate to `/register` to create your admin account
   723→   723→- ✅ If you have an account, navigate to `/login`
   724→   724→- ✅ Check that cookies are enabled in your browser
   725→   725→
   726→   726→**Problem**: API token not working
   727→   727→
   728→   728→- ✅ Ensure the `Authorization: Bearer TOKEN` header is set correctly
   729→   729→- ✅ Verify the token has the required permission for the endpoint
   730→   730→- ✅ Token is shown only once at creation — regenerate if lost by deleting and creating a new one
   731→   731→
   732→   732→**Problem**: Configuration not loading
   733→   733→
   734→   734→- ✅ Use the web admin interface to edit configuration
   735→   735→- ✅ Check logs in admin interface or container logs
   736→   736→
   737→   737→**Problem**: FFmpeg not working
   738→   738→
   739→   739→- ✅ Verify FFmpeg is installed on your host: `$(which ffmpeg) -version`
   740→   740→- ✅ Verify both `ffmpeg` and `ffprobe` binaries are mounted into the container
   741→   741→- ✅ Check FFmpeg arguments in debug logs
   742→   742→- ✅ Test with simple arguments first: `["-c", "copy"]`
   743→   743→- ✅ For hardware acceleration, verify `/dev/dri` device passthrough and driver library mount
   744→   744→
   745→   745→**Problem**: Hardware acceleration not working
   746→   746→
   747→   747→- ✅ Verify render node exists: `ls /dev/dri/` on host
   748→   748→- ✅ Confirm correct render node in config (usually `renderD128`)
   749→   749→- ✅ Verify VA-API driver library path for your distro is correctly mounted
   750→   750→- ✅ Confirm `group_add: [video, render]` is set in compose file
   751→   751→- ✅ Test with `vainfo` on the host to confirm VAAPI is functional
   752→   752→
   753→   753→**Problem**: Streams failing to play
   754→   754→
   755→   755→- ✅ Monitor channel status in admin interface
   756→   756→- ✅ Toggle between Go and FFmpeg modes in global settings
   757→   757→- ✅ Check per-source retry settings in source management
   758→   758→- ✅ Use dead stream management to mark problematic streams
   759→   759→
   760→   760→**Problem**: High CPU usage
   761→   761→
   762→   762→- ✅ Disable FFmpeg mode if hardware acceleration unavailable
   763→   763→- ✅ Use `-c copy` instead of transcoding in FFmpeg arguments
   764→   764→- ✅ Reduce `maxConnections` per source in admin interface
   765→   765→- ✅ Monitor active connections in dashboard
   766→   766→
   767→   767→**Problem**: Ad-break freezes on channels like Pluto TV
   768→   768→
   769→   769→- ✅ Enable FFmpeg mode with `-mpegts_flags initial_discontinuity` in pre-output args
   770→   770→- ✅ Add `-fflags +genpts+discardcorrupt+igndts` to pre-input args
   771→   771→- ✅ The stream watcher will detect and recover from prolonged stalls automatically
   772→   772→
   773→   773→**Problem**: HDHomeRun not discovered by Plex/Emby
   774→   774→
   775→   775→- ✅ Ensure your media server is on the same local network as KPTV Proxy
   776→   776→- ✅ HDHomeRun endpoints are restricted to RFC1918 addresses — public IPs are blocked
   777→   777→- ✅ If behind a reverse proxy, ensure `X-Forwarded-For` is set to the client's real IP
